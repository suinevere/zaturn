# Boot Splash (SUINE Logo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the SUINEVERE GAMES logo (`SUINE.TGA`) full-screen on first cold boot, fading in, holding while the real first-boot CD reads (game catalog scan, background-art preload, online typeahead build) run, then fading out — replacing today's silent stare at `HOUSE.TGA` during that window.

**Architecture:** A new module, `saturn/src/video/splash.{h,cxx}`, exposes one entry point `splash_show_once()`. It shows `SUINE.TGA` on VDP2 NBG0 through a new cache-bypassing loader (`title_bg_show_oneoff`, added to `title.cxx`/`title.h`), fades using the VDP2 hardware color-offset registers (cheap per-frame register writes, no VRAM/CRAM re-upload), and wraps the three existing preload calls during its hold phase. `main.cxx` calls it once, in place of the three calls it previously made directly. `display_scan_images()` gets one added `continue` so `SUINE.TGA` never appears in the Display Options background picker.

**Tech Stack:** C/C++ (SaturnRingLib / SGL), Sega Saturn VDP2. Build via `saturn/compile.bat` (run by the user, never by the assistant). Asset conversion via `tools/make_tga.py` / `tools/convert-backgrounds.sh` (Python + Pillow, safe for the assistant to run directly — it is not a Saturn compile).

## Global Constraints

- **Build command:** `saturn/compile.bat` — the assistant does NOT run it; the user builds. Make edits only. (Running `tools/convert-backgrounds.sh` or `tools/make_tga.py` directly is fine — it's a plain Python script, not the Saturn cross-compile.)
- **Source discovery:** `saturn/Makefile` globs every `.c`/`.cxx` under `src/` and adds every subdirectory to the include path (`find src -type d`). A new `saturn/src/video/splash.h`/`splash.cxx` needs **no** Makefile edit to be picked up.
- **Frame rate:** this codebase already assumes 60fps NTSC for frame-counted waits (e.g. `title.cxx`'s `SOFT_RESET_HOLD = 60` = ~1s). The splash's fade timings follow the same convention: no wall-clock timer, just `SRL::Core::Synchronize()`-counted loops.
- **VDP2 layer priority:** the debug text console lives on NBG3 at `Layer7` (top); background art (including the splash) lives on NBG0 at `Layer1` (below all text). The splash intentionally clears text rows first so no title text is drawn during it.
- **CD-read timing:** every first-boot CD read must happen before `music_cdda_play()` — the Saturn has one drive head and cannot play CD-DA while reading data. The splash's hold phase is exactly where the three existing preload calls already run, so this ordering constraint doesn't change.
- **TGA format:** the decoder (`tga_decode` in `title.cxx`) only accepts uncompressed 8bpp colour-mapped TGA, palette index 0 reserved as VDP2's transparent index. `tools/make_tga.py` already produces exactly this from a 320×224 PNG; `tools/assets/png/SUINE.PNG` is already tracked in git and is already exactly 320×224 RGBA, so it needs no edits.
- **Generated TGAs are gitignored:** `saturn/.gitignore` has `cd/data/**/*.TGA`, so `saturn/cd/data/TGA/SUINE.TGA` is a build artifact regenerated by `tools/convert-backgrounds.sh` on every build — never commit it.
- **`DISP_IMAGE_MAX = 8`** (`saturn/src/video/display.h`) caps the Display Options background picker, and the `/TGA` folder already holds exactly 8 real backgrounds. `SUINE.TGA` must be excluded from `display_scan_images()`'s registered list (**and** must never be admitted into the shared `g_cache`/`TgaImage g_cache[DISP_IMAGE_MAX]` Low Work RAM cache that array shares with the real 8 backgrounds) or it will silently steal a cache slot from one of them. This is why the splash uses a new non-caching loader instead of the existing `title_bg_show()`.
- **`SRL::VDP2::SetColorOffsetA(VDP2::ColorOffset&)` takes a non-const reference** — you must pass a named local variable, not a temporary (`SetColorOffsetA(ColorOffset(0,0,0))` will not compile).

bool title_bg_show_oneoff(const char *file) {
    TgaImage oneoff = { nullptr, nullptr, 0, 0, 0, false, { '\0' } };
    cd_enter_tga();
    bool decoded = tga_decode(file, false, 0xFFFFFFFFu, &oneoff);

    tga_image_free(&oneoff);

    SRL::VDP2::NBG0::ScrollEnable();
    return true;

- [ ] **Step 2: Create `saturn/src/video/splash.cxx`**

```cpp
/*----------------------
 | splash.cxx
 | Description: The boot splash: fades the SUINEVERE GAMES logo in, holds
 |   while the real first-cold-boot CD reads (game catalog, background art,
 |   online typeahead) run, then fades out. Fades using the VDP2 hardware
 |   color offset (SetColorOffsetA) -- a per-frame register write -- rather
 |   than rewriting the TGA's palette or re-uploading the bitmap every frame.
 | Author: suinevere
 | Dependencies: title.h, game_catalog.h, online.h, SRL
 ----------------------*/
#include "splash.h"
#include "title.h"
#include "game_catalog.h"
#include "online.h"
#include <srl.hpp>

/*----------------------
 | SPLASH_FADE_FRAMES / SPLASH_SETTLE_FRAMES
 | Description: Fade-in/fade-out length (90 frames = 1.5s at the 60fps NTSC
 |   field rate this codebase already assumes elsewhere, e.g. title.cxx's
 |   SOFT_RESET_HOLD) and the fixed settle pause held at full brightness
 |   after the real loads return, before fade-out begins -- so a run where
 |   everything is already cached never flashes the logo by unrecognizably
 |   fast. This is a flat add-on rather than a measured top-up to a floor:
 |   the three preload calls below are opaque frame-count-wise (no counter
 |   to read back without changing their signatures), and a flat 2s pause
 |   costs nothing extra when a real load already took several seconds.
 | Author: suinevere
 ----------------------*/
#define SPLASH_FADE_FRAMES   90
#define SPLASH_SETTLE_FRAMES 120

/*----------------------
 | g_splash_shown
 | Description: True once the splash has run. Plain static RAM, so it
 |   survives the soft-reset longjmp back into main()'s setjmp exactly like
 |   title.cxx's g_cache_ready -- a soft reset re-enters with everything
 |   already cached, so there is no real load left to hide.
 | Author: suinevere
 ----------------------*/
static bool g_splash_shown = false;

/*----------------------
 | splash_set_offset
 | Description: Sets VDP2 color offset A to (v,v,v) on all three channels
 |   and applies it. Offset A must already be enabled on NBG0 via
 |   UseColorOffset for this to have any visible effect.
 | Author: suinevere
 | Dependencies: SRL
 | Globals: N/A
 | Params: v -- signed offset, -255 (black) .. 0 (unmodified)
 | Returns: N/A
 ----------------------*/
static void splash_set_offset(int16_t v) {
    SRL::VDP2::ColorOffset offset(v, v, v);
    SRL::VDP2::SetColorOffsetA(offset);
}

/*----------------------
 | splash_show_once
 | Description: See splash.h.
 | Author: suinevere
 | Dependencies: title.h, game_catalog.h, online.h, SRL
 | Globals: g_splash_shown
 | Params: N/A
 | Returns: N/A
 ----------------------*/
void splash_show_once(void) {
    if (g_splash_shown) {
        preload_game_catalog();
        display_preload_images();
        ensure_online_typeahead();
        return;
    }
    g_splash_shown = true;

    for (int r = 0; r <= 28; r++) SRL::Debug::PrintClearLine(r);

    if (!title_bg_show_oneoff("SUINE.TGA")) {
        preload_game_catalog();
        display_preload_images();
        ensure_online_typeahead();
        return;
    }

    SRL::VDP2::NBG0::UseColorOffset(SRL::VDP2::OffsetChannel::OffsetA);

    for (int i = 0; i <= SPLASH_FADE_FRAMES; i++) {
        splash_set_offset((int16_t) (-255 + (255 * i) / SPLASH_FADE_FRAMES));
        SRL::Core::Synchronize();
    }

    preload_game_catalog();
    display_preload_images();
    ensure_online_typeahead();

    for (int i = 0; i < SPLASH_SETTLE_FRAMES; i++) SRL::Core::Synchronize();

    for (int i = 0; i <= SPLASH_FADE_FRAMES; i++) {
        splash_set_offset((int16_t) (0 - (255 * i) / SPLASH_FADE_FRAMES));
        SRL::Core::Synchronize();
    }

    SRL::VDP2::NBG0::UseColorOffset(SRL::VDP2::OffsetChannel::NoOffset);
    title_bg_hide();
}
```
