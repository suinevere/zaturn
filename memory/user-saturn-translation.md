The user is a Sega Saturn fan-translation / ROM-hacking hobbyist. Focus so far is
**T&E Soft golf games** (maker code T-114). They test patches on real hardware via
multiple ODEs — **Fenrir, Saroo, Terraonion MODE** — using **Pseudo Saturn Kai**
(on an Action Replay / comms-link cart), and in the **Yaba Sanshiro** emulator.
For distributing patches they use **DeltaPatcher** (xdelta GUI) and **Sega Saturn
Patcher** (knight0fdragon, `.ssp` format). Comfortable with hex/bytes, hardware,
and burning/flashing. Prefers concise, direct answers. See
[[reference-tande-english-activation]] and [[project-saturn-translate-mcp]].
